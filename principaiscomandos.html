Principais comandos do
Docker

Container:

docker create → cria um container sem iniciá-lo.

docker attach → conecta seu terminal ao container em execução.

docker kill → força a parada imediata de um container.

docker pause → pausa todos os processos dentro do container.

docker unpause → retoma os processos pausados.

docker top → mostra os processos rodando dentro do container.

docker stats → mostra consumo de CPU, memória e rede em tempo real.

docker commit → cria uma nova imagem a partir de um container em execução.

Imagens:

docker history → exibe as camadas de uma imagem.

docker tag → cria uma tag para uma imagem existente.

docker save -o → exporta uma imagem para um arquivo .tar.

docker load -i → importa uma imagem a partir de um arquivo .tar.

docker import → cria uma imagem a partir de um sistema de arquivos exportado.

docker export → container.tar → exporta o sistema de arquivos de um container para .tar.

Volume:

docker volume inspect → exibe detalhes de um volume.

docker volume prune → remove todos os volumes não usados.

Redes:

docker network inspect → mostra detalhes de uma rede.

docker network disconnect → desconecta um container de uma rede.

docker network prune → remove redes não utilizadas.

Gerenciamento do sistema:

docker version → mostra a versão do cliente e servidor Docker.

docker events → acompanha eventos em tempo real do Docker (criação, start, stop, etc).

docker builder prune → limpa dados de builds que não estão em uso.

docker login → autentica no Docker Hub (ou outro registry).

docker logout → encerra a sessão no registry.

docker search → pesquisa imagens no Docker Hub.
